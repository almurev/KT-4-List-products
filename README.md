# КТ4 — Вариант 1 «Учёт товаров»

Приложение работает с CSV-файлом `products.csv` и поддерживает:
- просмотр списка товаров;
- подсветку строк по правилам задания;
- отображение фото и цен со скидкой;
- добавление товара;
- редактирование товара;
- удаление товара;
- автоматическое обновление списка после любых изменений;
- кнопку «Назад» в форме добавления/редактирования;
- отдельные экраны с заголовками.

## Структура проекта

```text
kt4_products_pyqt6/
├── main.py
├── requirements.txt
├── products.csv
├── img/
├── models/
│   └── product.py
├── services/
│   └── product_repository.py
├── forms/
│   ├── main_window.py
│   └── product_form.py
└── utils/
    └── image_tools.py
```

Список товаров выводится из `products.csv`, в котором есть все нужные поля: артикул, фото, наименование, категория, описание, производитель, поставщик, цена, единица измерения, количество на складе и скидка. 

В интерфейсе реализованы:
- если скидка больше 15 %, строка подсвечивается зелёным `#2E8B57`;
- если товара нет на складе, строка подсвечивается голубым `#ADD8E6`;
- если скидка есть, старая цена отображается красным и перечёркнута, рядом показывается итоговая цена;
- добавление, редактирование и удаление сразу обновляют список.

## Что реализовано?

1. Создана модель `Product`, в которой хранятся все поля товара и считается итоговая цена.
В проекте создана модель Product, которая хранит все данные о товаре.
В ней реализована бизнес-логика расчёта итоговой цены с учётом скидки, а также проверки состояния товара (наличие на складе, наличие скидки и повышенная скидка).
Для точного расчёта цены используется тип данных Decimal, чтобы избежать ошибок округления.
Также реализованы методы преобразования из CSV и обратно для сохранения данных.
2. Создан `ProductRepository`, который читает и записывает `products.csv`.  
В проекте реализован класс ProductRepository, который отвечает за работу с файлом данных products.csv.
Он отделяет логику хранения данных от интерфейса, обеспечивая принцип разделения ответственности.
Repository выполняет загрузку товаров из CSV, сохранение изменений, а также операции добавления и удаления.
3. Реализовано главное окно со страницей списка товаров в виде таблицы.
4. Реализована форма `ProductForm` для добавления и редактирования товара.
5. Добавлены проверки:
   - цена не может быть отрицательной;
   - количество на складе не может быть отрицательным;
   - скидка вводится в допустимом диапазоне;
   - итоговая цена пересчитывается автоматически.
6. Реализованы действия:
   - добавление нового товара;
   - редактирование по двойному щелчку по строке;
   - удаление товара;
   - обновление таблицы после каждого изменения с помощью кнопки.
7. Для фото добавлены изображения-заглушки в папке `img`, чтобы проект выглядел завершённым и запускался сразу.


## Пошаговая инструкция для запуска

1. Установить виртуальное окружение
    ```bash
   python -m venv .venv
   ```
   (Если не получается или нет интерпретатора - Settings - Python - Python Interpeter - Home (Icon) - Add Local Interpreter)
2. Активировать окружение: 
   ```bash
   .venv\Scripts\activate
   ```
3. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустить приложение:
   ```bash
   python main.py
   ```
